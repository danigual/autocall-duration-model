# STARWARS_AUTOCALLS

Estimates the expected effective lifespan (`avg_duration_months`) of autocallable structured notes at the time of quotation, using only information available at RFQ date.

## Structure

```
train.py                   # training entry point
api/main.py                # FastAPI inference server
src/autocall/
    data/loader.py         # CSV ingestion
    features/              # temporal, barrier, volatility transformers
    models/                # Ridge baseline, LightGBM, XGBoost
tests/                     # pytest suite (82 tests)
artifacts/model.joblib     # serialized pipeline (generated by train.py)
```

## Installation

```bash
conda env create -f environment.yml
conda activate autocall
pip install -e .
```

## Training

Place `rfqs.csv`, `daily_volatility.csv`, and `underlyings_reference.csv` in the project root, then:

```bash
python train.py
# optional: python train.py --data-dir data/ --artifacts-dir artifacts/
```

The script filters to executed RFQs, applies a chronological train/test split at `2022-01-01`, trains Ridge + LightGBM + XGBoost, reports MAE/RMSE/R²/MAPE on the held-out test set, and saves the best model to `artifacts/model.joblib`.

## API

Start the server (artifact must exist):

```bash
uvicorn api.main:app --reload
```

Interactive docs at `http://localhost:8000/docs`.

**Health check**

```bash
curl http://localhost:8000/health
```

```json
{"status": "ok", "model_loaded": true}
```

**Predict duration**

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "product_type": "Kessel Run Snowball",
    "basket_type": "worst_of",
    "underlyings": "CLNE|DRC|KYBR",
    "autocall_barrier_pct": 1.0,
    "protection_barrier_pct": 0.6,
    "no_call_period_months": 3.0,
    "observation_frequency": "3M",
    "quoted_implied_vol": 0.32,
    "requested_date": "2023-06-15",
    "start_date": "2023-07-01",
    "end_date": "2026-07-01"
  }'
```

```json
{"avg_duration_months": 18.43}
```

The prediction is clipped to `[0, nominal_duration]`. Missing or malformed fields return HTTP 422.
